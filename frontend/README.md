# LanguageApp frontend

A LanguageApp React/Vite felhasználói felülete. Az alkalmazás bemutatása, a szükséges konfiguráció és a klónozástól az első belépésig vezető Dockeres telepítés a [projekt fő README-jében](../README.md) található.

A teljes alkalmazás kipróbálásához a fő útmutatót kövesd; külön Node.js-telepítés vagy `npm install` nem szükséges.
